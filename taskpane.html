Please sideload your add-in to see app body.

Review how the add-in works

  1. Create a new message in New Outlook.
  2. Add a recipient whose SMTP domain is not listed in src/launchevent/internal-domains.js.
  3. Verify that a caution banner appears while composing if the message is not already marked secure.
  4. Select Send. If the message is not secure, choose Send Securely to add the Purview secure-send marker and send the message.

This add-in warns when external recipients are detected and the message does not have the secure-send header.

Before testing in your environment, replace the domain list and Purview secure-send header configuration in src/launchevent/internal-domains.js.
